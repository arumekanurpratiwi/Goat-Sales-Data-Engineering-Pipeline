# Pentaho ETL

Folder ini berisi file ETL (.ktr) yang dikembangkan menggunakan **Pentaho Data Integration (PDI)**.

## ETL Pipeline

Pipeline ETL meliputi proses:

- Extract data dari dataset 
- Data Cleansing
- Data Validation
- String Manipulation
- Insert & Update Data
- Load data ke PostgreSQL

## Output

Hasil proses ETL berupa dataset yang telah terintegrasi dan siap digunakan pada proses analisis menggunakan PySpark dan visualisasi menggunakan Power BI.
