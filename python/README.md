# Python Scripts

Folder ini berisi script Python yang digunakan dalam proyek **Goat Sales Data Engineering Pipeline**.

## Files

| File | Deskripsi |
|------|-----------|
| analyze_goat.py | Script analisis data penjualan menggunakan PySpark. |
| dag_analyze_goat.py | Workflow Apache Airflow untuk mengotomatisasi proses analisis data. |
| Masking_Enkripsi.py | Implementasi data masking dan enkripsi untuk melindungi data sensitif pelanggan. |

## Features

- Data Analytics
- Workflow Automation
- Data Masking
- Data Encryption
- Business Insight Generation

## Technologies

- Python
- Apache Airflow
- PySpark
