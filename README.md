🐐 Goat Sales Data Engineering Pipeline

📌 Overview
Proyek ini merupakan Final Project Data Engineer Bootcamp Celerates yang bertujuan membangun pipeline data engineering end-to-end untuk mengolah data penjualan kambing di Provinsi Jawa Barat.

Pipeline mencakup proses data ingestion, ETL, data warehouse, workflow orchestration, analisis menggunakan PySpark, serta visualisasi dashboard menggunakan Power BI untuk mendukung pengambilan keputusan berbasis data.

🛠 Tech Stack
- Python
- SQL
- PostgreSQL
- Pentaho Data Integration
- Apache Airflow
- Apache Spark (PySpark)
- Power BI

📊 Business Problems
- Data penjualan masih tersebar di berbagai sumber.
- Belum terdapat pipeline otomatis untuk proses ETL.
- Analisis penjualan masih dilakukan secara manual.
- Belum tersedia dashboard sebagai media monitoring.

🎯 Objectives
- Mengintegrasikan berbagai sumber data.
- Membangun pipeline ETL otomatis.
- Menghasilkan data warehouse menggunakan PostgreSQL.
- Melakukan analisis menggunakan PySpark.
- Menampilkan dashboard interaktif menggunakan Power BI.

⚙️ Pipeline Architecture
CSV → Pentaho ETL → PostgreSQL Data Warehouse → Apache Airflow → PySpark Analytics → Power BI Dashboard

📈 Analytics
Dashboard menghasilkan beberapa insight:
- Tren penjualan bulanan tahun 2024
- Pola penjualan berdasarkan metode transaksi
- Rata-rata harga kambing per jenis

🔒 Data Security
- Data Masking
- Data Encryption
